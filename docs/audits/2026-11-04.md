# Raport audytu i optymalizacji `konuzastro-tracker`

Data audytu: 4 listopada 2026. Aktualizacja po etapie 6: 5 listopada 2026. Baza: `main`, `ce1bf7b`. Raport obejmuje pięć zamówionych obszarów i wdrożenie wybranych poprawek. Nie stwierdzono potwierdzonego problemu krytycznego. Nie jest to gwarancja braku pozostałych błędów ani audyt penetracyjny.

## Wynik

W etapach 1 i 2 wdrożono pięć zmian:

1. Ranking wyszukiwania w katalogu jest liczony raz na obiekt, zamiast wielokrotnie w komparatorze sortowania.
2. Granice nocy używają dwóch osobno przeliczonych lokalnych południ; zakres wyszukiwania uwzględnia doby 23- i 25-godzinne.
3. Nieoczekiwane błędy API i odczytu plików zwracają HTTP 500. Brak pliku statycznego nadal zwraca 404.
4. Domyślna lokalizacja Skyshota wynika z lokalizacji modułu serwera, niezależnie od katalogu uruchomienia procesu.
5. Shadery WebGL są jawnie odłączane i usuwane; błędy kompilacji lub linkowania również zwalniają utworzone zasoby.

Weryfikacja po etapie 6 obejmuje `npm run typecheck`, `npm test` — **167/167 testów w 29 plikach**, `npm run build` wraz z PWA oraz `git diff --check`. Próby Chromium objęły mapę nieba, katalog, odtwarzanie, sterowanie 3D i eksport planera. W etapie 6 sprawdzono odzyskanie projektu po awarii IndexedDB, ponowienie zapisu na ekranie o szerokości 600 px oraz odczyt po przeładowaniu strony. Próba zakończyła się bez błędów JavaScript.

## Zakres i sposób pracy

- Skan higieny objął 90 śledzonych plików kodu, w repozytorium liczącym 221 śledzonych plików przed zmianami. Przeglądy tematyczne objęły `src/lib`, `src/state`, `src/workers`, komponenty i widoki, `server/`, `scripts/`, konfigurację Vite oraz testy.
- Pięć zwiadów wykonali osobni badacze `gpt-5.6-luna`, `medium`; model i poziom potwierdzono w metadanych wykonania. Limit środowiska pozwalał na trzech badaczy jednocześnie, więc zadania uruchomiono w dwóch falach. Dostępnego `invoke_subagent` nie było; użyto profilu `explorer_luna`.
- Orkiestrator tej sesji działał jako `gpt-6-astra`, `xhigh`; nie jako wskazany w instrukcji routingu Sol. Ograniczoną poprawkę DST przygotował `implementer_luna`, którego metadane potwierdziły `gpt-5.6-luna`, `xhigh`. Integrację i pozostałe poprawki wykonał orkiestrator.
- Narzędzia grafu `codebase-memory-mcp` były niedostępne. Zastosowano odczyt źródeł, `git ls-files` i `rg`. Nie ma potwierdzonej generacji indeksu ani grafowego dowodu kompletności.
- Zwiad i recenzja były tylko do odczytu na poziomie instrukcji, przy uprawnieniach `workspace-write`. Początkową próbę recenzji zatrzymał limit użycia. Po wznowieniu niezależny `reviewer_sol` (`gpt-5.6-sol`, `max`, potwierdzone w metadanych) ukończył przegląd całego diff: **akceptacja, brak uwag blokujących i znalezionych regresji**. Wskazał A10 jako nieblokujące ograniczenie testów. Nie zmieniał drzewa, indeksu, HEAD ani gałęzi i nie powtarzał kontroli orkiestratora.
- Pominięto zależności, wygenerowane dane, pliki binarne i istniejące nieśledzone `.codex-attachments/` oraz `astro-regressor-main/`. Nie zmieniono danych astronomicznych, konturów, odległości, zależności ani tych katalogów. Nie wykonano commita.

Numery linii w znaleziskach poniżej odnoszą się do bazy `ce1bf7b`; po poprawkach mogą być przesunięte. Priorytet oznacza stosunek korzyści do ryzyka zmiany, a nie automatycznie poziom podatności bezpieczeństwa.

## Higiena, pokrycie i odrzucone zgłoszenia

- Skan nie znalazł typu `any` ani dyrektyw `@ts-ignore`/`@ts-expect-error`. Osiem `as unknown as` dotyczyło testów i atrap, nie potwierdzonego błędu produkcyjnego. Wartości HTML `step="any"` nie są osłabieniem TypeScript.
- `console.*` obejmuje diagnostykę skryptów, start serwera i obsługę błędów. Nie należy usuwać tych wywołań mechanicznie.
- Nie potwierdzono nieużywanego eksportu ani zakomentowanego kodu wymagającego usunięcia. To wynik skanu tekstowego i sprawdzenia referencji, nie dowód kompletności grafu.
- Pliki ponad 300 fizycznych linii w bazie: `SkyDome.tsx` 1467, `Space3D.tsx` 1282, `app.css` 875, `build-data.ts` 618, `FramingPanel.tsx` 425, `store.ts` 421, `core.test.ts` 347, `CatalogView.tsx` 340, `AltitudeChart.tsx` 305. Rozmiar jest kosztem utrzymania, sam nie dowodzi usterki. Nie dzielono ich bez potrzeby.
- `useCatalogVisibility` korzysta z trwałego workera i cache wektorów; nie potwierdzono liczenia całego katalogu synchronicznie na wątku UI. `useNight` i siatki czasu mają już współdzielenie/memoizację.
- W sprawdzonych ścieżkach nie znaleziono subskrypcji `useStore()` bez selektora. Zmiana koloru, planu czy ulubionych powinna aktualizować właściwe karty; to nie wystarcza do zgłoszenia zbędnego renderu.
- Wirtualizacja katalogu jest aktywna: podczas kontroli 7877 wyników nie tworzyło 7877 kart. Sprawdzono widok po przewinięciu i zmianie szerokości.
- Zgłoszenie błędu `uniformMatrix3fv(..., true, ...)` **odrzucono**. Dotyczyło pomylenia WebGL1 z WebGL2. Źródło używa WebGL2; eksperyment z 43 wywołaniami w bazie nie zwrócił błędu GL, a mapa gwiazd była poprawna. Specyfikacja [WebGL2](https://registry.khronos.org/webgl/specs/latest/2.0/) opiera semantykę na OpenGL ES 3.0; nie zmieniono poprawnej macierzy.
- Cleanup Three.js, tekstur, geometrii i rendererów istnieje; worker HiPS zamyka `ImageBitmap`. Nie potwierdzono szerokiego wycieku tych zasobów. Nie wykonano długiego testu stabilności pamięci GPU.
- Serwer i AstroBin mają test integracyjny w `productionServer.test.ts`; nie oznaczono ich jako całkowicie nieprzetestowanych. Pozostałe luki: wolny upload, rozłączenie podczas Sharp, zbyt duże odpowiedzi usług, niepoprawny wynik rzeczywistego solvera, pełny bridge Rust, skrypty pobierania i budowania. Nie wyliczano procentowego pokrycia instrukcji.
